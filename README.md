# Contract Radar

A Forge app for Jira: the contract and renewal register for business teams. It shows which contracts must be
decided before they renew on their own, warns when a purchase request duplicates a tool the company already
pays for, and pushes the register into the Atlassian Teamwork Graph through a connector, so Rovo Search,
Rovo Chat and agents can answer "do we already pay for a tool that does X?".

Built for Codegeist 2026. Documentation and the privacy policy for the app will live in this repository.
